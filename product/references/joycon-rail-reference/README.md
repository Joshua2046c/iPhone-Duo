100.8是带端部轮廓的总跨度，不能误称为完整等截面导向长度。入口处外唇和槽底并非齐头：外侧平面端界限约Y=165.817，唇内侧约166.812，槽底169.632，主体包络至170.4，形成圆滑退让的入口。闭端为圆滑鼻端加内部止挡。曲面来自三角网格，未将网格端点精度冒充原始圆角半径或加工公差。入口应继续以原网格局部截面为依据重建，不用一个任意倒角替代。

上下唇缺口可能用于锁止或让位，但仅凭STL不能确定其功能，不能声称Joy-Con已能锁止。左右功能平面的坐标与面积已分别提取；不以不同三角剖分的顶点最近距离作为左右形状不对称的证据。

## 与当前 iPhone Duo 壳的差异

对照CAD版本`47c9af7982d1d575ddfbe6c1163de13aa4c32dfa0051a0a99be68dfc979637cd`，该表保留更新前版本的比较依据；后续实施状态见文末。

| 项目 | 当前参数化初稿 | 上传参考 |
|---|---:|---:|
| 轨道纵向包络 | 96 | 100.8 |
| 轨道在底板上方的高度 | 7.6 | 14（源模型自身高度） |
| 内槽高度 | 4.6 | 10 |
| 外侧开口高度 | 2.4 | 7.6 |
| 唇后槽深 | 2.8 | 2.2 |
| 唇径向厚度 | 0.7 | 0.7 |
| 外面至槽底总深 | 3.5 | 2.9 |
| 闭端止挡距外轮廓端部 | 3 | 10.1 |
| 缺口位置/形式 | 靠闭端、槽底凹位 | 靠入口、上下唇边缺口 |

当前初稿的唇后槽深2.8不等于上传模型的外面至槽底总深2.9；两者必须在相同基准下比较。参考件Z=0不是当前手机背板或屏幕平面，后续应用时需按整体装配决定垂直偏置，不能直接覆盖盖板、方桩及音量机构的位置。

后续重建仅调整双轨功能截面、导向范围、入口和止挡/缺口。保留用户已确定的滑轨与底壳一体、居中且对称、半包后盖、方桩上盖、左声孔和右双键；保留“轨道不附加外壳倒角”的要求。轨道应刚性定位，不能为迎合96 mm翼部长度而缩放参考配合结构。现有翼部与100.8 mm参考轨道之间的端部衔接需要重新处理，参考件两轨144 mm外间距不采用。

## 验证与复现

`measure.py`以trimesh读取原文件，检查三角面数、连通组件与闭合性，分别聚合双轨的轴向平面及其范围，并在规则段、缺口段和唇厚内/外做截面。`measurements.json`记录源哈希、坐标、关键值、单位假设和未实配状态；`rail-sections.png`为直接从网格求交得到的证据图。

参考分析后，用户已明确要求更新当前滑轨。现已应用于CAD版本9c37fbdbdb9a76bed04e8407d3b64fd3f4383732bacf4bb02bb7b3d9ce0bc2f7：功能截面、长度、闭端止挡和唇边缺口按测量值；入口为网格采样样条与纵向4 mm圆头包络相交的解析重建。安装宽保留5 mm，底面Z=-2.4，外侧面X=±86.6、中心Y=-3.45，其他对象未变。不是原网格逐三角面复制，未采用原手机框的内侧过渡。不代表实物滑入、锁止、释放、打印收缩或受力寿命已验证。
